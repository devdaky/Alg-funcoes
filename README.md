# Alg-funcoes

Crie as funções em um único código local SEM utilizar nenhuma variável global.

1. H:m;s Cálculo

2.isPar (verifica se o número é par, retorna verdadeiro se é par e falso se é impar)

3.isImpar (verifique se o número é ímpar, retorna verdadeiro se for ímpar, e falso se for par)

4.media (cálculo médio entre dois números)

5.maior (retorna o maior valor de dois números)

6.menor (retorna o menor valor de dois números)
